# Slavynix

Инструмент для переозвучивания выбранного персонажа в фильме с помощью пользовательской RVC-модели.

## Архитектура

Проект разбит на модули:

- `video_processing.py` — извлечение аудио из видео и финальная сборка видео с новой дорожкой.
- `audio_processing.py` — чтение/запись аудио, обработка сегментов, сборка итоговой дорожки по чанкам.
- `diarization.py` — диаризация, эмбеддинги голосов, сопоставление персонажа по референсу.
- `rvc_inference.py` — запуск RVC-инференса по сегментам (через внешний RVC-скрипт).
- `gui.py` — графический интерфейс и orchestration пайплайна.

## Подготовка RVC-модели

1. Убедитесь, что у вас есть папка модели с:
   - `*.pth` — веса модели.
   - `*.index` — индекс для retrieval.
   - `config.json` или `*.json` — конфигурация модели.
2. Установите любой рабочий RVC-инференс (например, локальную копию RVC с `infer_cli.py`).
3. В GUI укажите путь к RVC-скрипту (`infer_cli.py` или вашему wrapper), который принимает:
   - входной WAV,
   - путь к `.pth`,
   - путь к `.index`,
   - параметры pitch/index_rate/f0_method,
   - путь для выходного WAV.

> Программа вызывает внешний RVC-скрипт как отдельный процесс. Это надежный способ интеграции без дублирования кода RVC.

## Как работает пайплайн

1. Извлекаем аудиодорожку из фильма.
2. Диаризация (speaker diarization) по всему аудио.
3. Определяем сегменты выбранного персонажа:
   - по референс-аудио (если указано), либо
   - вручную выбираем нужный speaker label из списка.
4. Только найденные сегменты пропускаются через RVC-инференс.
5. Собираем итоговую аудиодорожку, не затрагивая остальные голоса/шумы.
6. Мержим дорожку обратно в видео.

## Улучшения (идеи)

- Привязка реплик через субтитры (`.srt`) для более точной разметки сцен.
- Автоматическая калибровка pitch shift по целевому голосу.
- Кэширование сегментов и батч-обработка на GPU.

## Запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите GUI:
   ```bash
   python gui.py
   ```
